# Quantity Measurement Backend

A professional Quantity Measurement Application developed incrementally using Core Java, Spring Boot, and Microservices Architecture.

## Features

- Length Measurement
- Weight Measurement
- Temperature Measurement
- Volume Measurement
- Unit Conversion
- Arithmetic Operations
- REST APIs
- Authentication & Authorization
- Database Integration
- React Frontend Integration
- Microservices Architecture

---

## Tech Stack

### Backend
- Java 21
- Maven
- Spring Boot
- Spring Security
- JWT
- OAuth2
- PostgreSQL
- JPA / Hibernate

### Frontend
- React
- Vite
- Axios
- Material UI
